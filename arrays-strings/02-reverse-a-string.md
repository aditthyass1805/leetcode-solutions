# Reverse a String

- **LeetCode:** [Reverse String](https://leetcode.com/problems/reverse-string/)
- **Approach:** Use two pointers at the beginning and end of the character array, swapping values until they meet.
- **Time complexity:** $O(n)$
- **Space complexity:** $O(1)$ auxiliary space

## Notes

The function modifies the string in place. The local tests cover a regular word and an empty string. This is a practice solution and has not been submitted to LeetCode.
