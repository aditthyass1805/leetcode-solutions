# Two Sum

- **LeetCode:** [Two Sum](https://leetcode.com/problems/two-sum/)
- **Approach:** Check every pair of values and return the indices whose values add to the target.
- **Time complexity:** $O(n^2)$
- **Space complexity:** $O(1)$ auxiliary space

## Notes

The local program uses a static result array so the returned pair remains valid after the function returns. The typical test uses four values; the edge test uses two equal values. This is a practice solution and has not been submitted to LeetCode.
