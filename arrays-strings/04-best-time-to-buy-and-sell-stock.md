# Best Time to Buy and Sell Stock

- **LeetCode:** [Best Time to Buy and Sell Stock](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)
- **Approach:** Track the lowest price seen so far and the largest profit possible at each later price.
- **Time complexity:** $O(n)$
- **Space complexity:** $O(1)$

## Notes

The algorithm allows one buy and one later sell. A single-price input is handled as an edge case with zero profit. This is a practice solution and has not been submitted to LeetCode.
