# Move Zeroes

- **LeetCode:** [Move Zeroes](https://leetcode.com/problems/move-zeroes/)
- **Approach:** Maintain the next position for a non-zero value and swap each non-zero value into that position.
- **Time complexity:** $O(n)$
- **Space complexity:** $O(1)$

## Notes

The operation is performed in place and preserves the relative order of non-zero values. The tests cover mixed values and an array containing only zeroes. This is a practice solution and has not been submitted to LeetCode.
