# Binary Search

- **LeetCode:** [Binary Search](https://leetcode.com/problems/binary-search/)
- **Approach:** Repeatedly compare the target with the middle element and discard the half that cannot contain it.
- **Time complexity:** $O(\log n)$
- **Space complexity:** $O(1)$

## Notes

The input array must be sorted in ascending order. The tests cover a found target and a one-element array where the target is absent. This is a practice solution and has not been submitted to LeetCode.
